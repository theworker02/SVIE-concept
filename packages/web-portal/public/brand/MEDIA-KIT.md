# Brand & Media Kit

Assets for decks, data rooms, and portal embedding.

## Files

| File | Format | Use |
|------|--------|-----|
| `svie-logo.svg` | Vector square | Favicon, app icon, slides |
| `svie-logo.png` | Raster square | README, Notion, email |
| `svie-wordmark.svg` | Horizontal | Letterheads, portal headers |
| `README.md` | Text | Usage rules |

Copied into the portal at `packages/web-portal/public/brand/`.

## Color tokens

```css
--graphite: #12151A;
--ink:      #E8ECF1;
--steel:    #7A8A9A;
--line:     #3A4554;
--amber:    #D4A017;
```

## Do

- Keep amber accent for the vapor / diligence signal  
- Pair with IBM Plex Sans / Mono in product UI  
- Leave ≥8% clear space around the mark  

## Don’t

- Recolor to purple/glow startup gradients  
- Stretch the V mark  
- Place the logo on busy photography without a graphite plate
