# SVIE Brand Kit

Official visual identity for **SVIE** (Supercritical Vapor-Injection Engine).

| File | Use |
|------|-----|
| `svie-logo.svg` | App icon, favicon source, square lockups |
| `svie-logo.png` | README / pitch raster (1024-class) |
| `svie-wordmark.svg` | Horizontal header / letterhead |

## Palette

| Token | Hex | Role |
|-------|-----|------|
| Graphite | `#12151A` | Field |
| Ink | `#E8ECF1` | Primary type |
| Steel | `#7A8A9A` | Secondary |
| Amber | `#D4A017` | Accent / vapor line |
| Line | `#3A4554` | Rules |

## Usage

- Prefer SVG in product UI; PNG for Markdown hosts that strip SVG.
- Do not recolor the amber vapor accent without brand review.
- Clear space: ≥ 8% of mark width on all sides.
- Portal copies live under `packages/web-portal/public/brand/`.
