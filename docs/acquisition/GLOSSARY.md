|------|---------|

| **HEX** | Exhaust counter-flow heat exchanger (fuel-side recuperation) |

| **VCR** | Variable compression ratio |

| **AERO-SKIN** | Active diffuser / DRS body aero |
| **CELL-VAULT** | Structural underfloor energy vault |
