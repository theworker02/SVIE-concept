## Layout (analog-first luxury)

Driver-centric 2-seat cockpit. **Not** a screen wall. Analog needles, milled rotaries, guarded toggles, jeweled telltales. One recessed ≤10.25″ glass for **CarPlay Ultra** (guest) — motor-coverable in brushed aluminum.

| Element | Spec |
|---------|------|
| Seating | 2 × shell seats, 6-way (driver), 4-way (pass) |
| Steering | Round 360 mm (yoke optional) — **no** touchpads for climate |
| Cluster | Analog speed + tach; thin caption strip only |
| Center glass | ≤10.25″, retractable cover, CarPlay Ultra host |
| Stack | CNC Al HVAC dials, volume roller, drive-mode rotary |
| HVAC | Dual-zone **physical** — Ultra may remote, dials win |
| OS | **AETHER-OS** |

## HMI rules

1. SENTINEL / hazard = hard jewels — never menu-only.  
2. No screens on doors, mirrors, or headrests.  
3. CarPlay Ultra is a **guest**; hardware is truth.  
4. Quiet luxury: instrument craft, not app chrome.
